# 🔴 VCN Wear — La marca del Rayismo

Sitio web desarrollado para **VCN Wear**, una marca de ropa vinculada a la cultura del Rayismo.

La web presenta diferentes equipaciones y diseños de la marca, acompañados de contenido relacionado con la historia y la identidad del Rayo Vallecano.

## 🚀 Demo

[Ver aplicación online](https://vcnwear.netlify.app/)

## ✨ Funcionalidades

* 👕 Presentación de diferentes equipaciones y diseños
* 📸 Galería de contenido visual
* 🔗 Enlaces a Instagram
* 🏟️ Contenido relacionado con la historia del club
* 📝 Interacción mediante formulario
* 📱 Diseño adaptado a diferentes dispositivos

## 🛠️ Tecnologías

* HTML
* CSS
* JavaScript
* Git / GitHub
* Netlify

## 🎯 Objetivo

El objetivo del proyecto fue desarrollar una web para una marca de ropa vinculada al Rayismo, combinando presentación de producto, contenido visual e información relacionada con la historia e identidad del club.

El proyecto permitió trabajar la creación de una interfaz web desde cero y la integración de diferentes elementos interactivos y de contenido.
